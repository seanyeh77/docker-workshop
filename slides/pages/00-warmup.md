# 學習目標

1. 說明 Image、Container、Registry 的定義
2. 撰寫 `Dockerfile`，將程式與環境封裝為 Image
3. 以 `-d`、`-p`、`-v` 將 todo app 部署為網站
4. 以 `docker compose up` 取代冗長的 `docker run` 指令
