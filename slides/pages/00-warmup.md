# 3 小時後，你會自己做到

1. 說出 Image、Container、Registry 各是什麼
2. 寫一份 `Dockerfile`，把程式和環境打包成 Image
3. 用 `-d`、`-p`、`-v` 把 todo app 跑成一個網站
4. 用一行 `docker compose up` 取代一長串指令
